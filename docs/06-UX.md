# UX Specification

## Navigation

Primary navigation:

- Dashboard
- Properties
- Compare
- Map
- Search Profiles
- Analytics
- Reports
- Settings

For MVP, Analytics and Reports may be placeholders or limited.

## Dashboard

The dashboard should prioritize decision-making, not generic metrics.

Primary question:

> What should I look at next?

Recommended sections:

### Top Candidates
Highest-scoring active properties.

### Worth Visiting
Properties manually or automatically flagged for a showing.

### Recently Added
Newest property records.

### Watch List
Interesting but not action-ready.

### Best Setting
Properties with strongest setting scores.

### Best Value
Strong scores relative to projected total investment.

### Rejected by Profile
Properties that failed a hard rule, retained for inspection and override.

## Property card

Recommended compact card content:

- address
- asking price
- overall score
- score label
- town
- drive time
- setting summary
- projected renovation
- projected total investment
- lifecycle status
- hard-reject badge if applicable

## Property detail

Suggested tabs/sections:

### Overview
- key facts
- score
- score explanation
- listing URL
- status

### Setting
- view types
- acreage
- water
- pastoral/open land
- privacy
- nuisance indicators

### Financials
- asking price
- estimated purchase price
- taxes
- renovation estimate
- total investment
- optional resale estimate

### Renovation
- line items
- low / expected / high
- contingency
- scope fit with profile

### Due Diligence
Later:
- flood
- wetlands
- septic
- well
- title
- zoning
- permits
- insurance

### Visits
- notes
- ratings
- photos
- follow-up actions

### History
- status changes
- scores under different profile versions
- rejection/override history

## Search profile editor

This must be a first-class UI.

Suggested sections:

### Geography
- commute anchor
- max drive time
- town ordering / tiers

### Budget
- purchase target / max
- renovation target / max
- total project target / max

### Setting preferences
Drag-and-drop ranking plus numeric weights.

### House style
Drag-and-drop ranking plus weights.

### Renovation tolerance
Preset level plus customizable included/excluded scopes.

### Deal breakers
For each criterion:

- Hard reject
- Penalize
- Neutral
- Bonus (where relevant)

### Score category weights
Sliders or numeric controls.

## Comparison view

Desktop-first table comparing 2-4 properties.

Sticky left-hand labels.

Highlight:
- best score in row
- hard failures
- missing information
- user-selected favorite

## Mobile UX

Mobile should prioritize:

- quick property review
- score explanation
- notes during showings
- photos
- reject/watch/visit buttons

Complex profile configuration can remain easier on desktop.

## Interaction principle

A user should never have to wonder:

> Why did this property score this way?

Every significant number should be drillable to its rules and facts.
