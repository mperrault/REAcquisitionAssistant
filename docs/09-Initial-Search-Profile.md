# Initial Search Profiles — Quiet Corner Second Home

This file is seed configuration, not application code.

## Profile

Name: Quiet Corner Second Home Rehab

Strategy:

Acquire a dated or cosmetically unattractive home on an exceptional property, then complete a moderate renovation. Prioritize scarce setting/resale attributes over current interior finishes.

## Variant Profile

Name: Quiet Corner Turnkey

Strategy:

Acquire a move-in-ready Quiet Corner second home with the same geography, setting, style, and hard-reject preferences, but avoid properties that require meaningful renovation.

Budget differences:

- renovation budget target: $7,500
- renovation budget max: $15,000
- total-project target: $400,000
- total-project max: $450,000

Renovation interpretation:

The Turnkey profile treats paint, lighting, landscaping, and very light flooring as acceptable refresh work. Kitchen, bathroom, layout, systems, siding, windows, structural, and addition work are penalties rather than desired renovation fit.

## Renovation tolerance

Level: Moderate Remodel

Acceptable:

- paint
- flooring
- kitchen
- bathrooms
- lighting
- landscaping
- windows
- siding
- deck / porch
- minor layout changes

Generally not desired:

- foundation repair
- structural rehabilitation
- whole-house gut renovation
- major addition
- extensive electrical/plumbing replacement as the primary project

## Hard deal breakers

Default hard reject:

- busy road
- flood zone
- HOA
- steep driveway
- electric baseboard heat
- high-voltage power lines nearby
- visible cell tower
- railroad nearby
- drive time over 40 minutes

## Acceptable / initially neutral

- shared driveway
- oil heat
- propane
- well
- septic
- no garage
- wetlands

Wetlands should be assessed contextually rather than always scored neutrally.

## Budget

The initial strategic planning budget discussed is approximately $400,000 total project cost.

Purchase-price, renovation, and total-project thresholds must remain configurable in the application rather than embedded in scoring code.

A practical default profile can start with:

- target asking/purchase range: approximately $250,000-$350,000
- total-project target: approximately $400,000

These values should be confirmed/edited in the application before being treated as scoring constraints.

## Search philosophy

Prefer:

> mediocre house + exceptional property

over:

> renovated house + ordinary setting

The system should reward assets that cannot readily be created later:

- views
- pastoral setting
- desirable location
- water relationship
- historic character
- resale appeal

while treating kitchens, baths, flooring, paint, and other moderate-renovation items as correctable.
